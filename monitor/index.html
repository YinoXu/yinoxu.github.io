Data coverage, privacy, and interpretation
Public access No account or password is required; anyone with this URL can read the current snapshot. The noindex directive discourages search indexing but does not make the page private.
What is shown Running lab jobs include Slurm username, partition, compute node, GPU resource and node-local IDX, allocated GPU units, allocated CPU cores, and runtime.
What is withheld Job IDs and names, commands and scripts, environment variables, filesystem paths, stdout/stderr and other logs, SSH credentials, passwords, and collector tokens are not sent to this page.
Allocation semantics GPU and CPU values are scheduler reservations, not hardware utilization. A GPU unit may be one full GPU or one configured MIG slice. IDX is a node-local Slurm GRES index, not a permanent GPU UUID.
Public read-only view · URL access · no login or password For operational awareness only—not a scheduler guarantee
