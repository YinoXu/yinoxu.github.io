Load Slurm jobs locally to see individual wait times

Run this in a Betty SSH terminal, replacing YOUR_LAB_ACCOUNT with the Slurm account you want to inspect. Paste its output below. Data stays in this browser tab; the page does not upload or store it.

squeue -r --noheader --account=YOUR_LAB_ACCOUNT --format='%u|%t|%P|%V|%S|%R|%i|%C'

Importing is optional. Queue time means elapsed time since submission, not how long a job will still wait.

Data coverage, privacy, and interpretation
Public access No account or password is required; anyone with this URL can read the current snapshot. The noindex directive discourages search indexing but does not make the page private.
What is shown Aggregate GPU and CPU allocations, resource-pool availability, queue statistics, anonymous node states, and storage quotas.
What is withheld Member usernames, individual job details, job IDs and names, commands and scripts, environment variables, filesystem paths, stdout/stderr and other logs, SSH credentials, passwords, and collector tokens are not sent to this page.
Allocation semantics GPU and CPU values are scheduler reservations, not hardware utilization. A GPU unit may be one full GPU or one configured MIG slice.
Public read-only view · URL access · no login or password For operational awareness only—not a scheduler guarantee
